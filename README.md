# 国土交通省 道路交通センサス・不動産価格指数・建設工事費

国土交通省の統計のうち、道路交通センサスの交通量、不動産価格指数と不動産取引件数・面積、建設工事費デフレーター、公共工事設計労務単価、建設業者・宅地建物取引業者などへの行政処分、地方整備局・北海道開発局の直轄工事・業務の入札結果、国土交通白書の本文を、SQL で集計・地図表示できるテーブルにしたデータセットです。交通量は道路の区間の形を持つので、出店や施設配置の検討で沿道の交通量を地図に重ねられます。

- 入札結果: 局ごとに列の並びと見出しが少しずつ違う Excel を、1 行 = 案件 × 入札業者の 1 つのテーブルにまとめています。和暦や Excel のシリアル値の日付を日付型にし、入札額の欄の「辞退」「無効」などの文字を状態の列に分けています。業者名は元の表記のままです
- 国土交通白書: PDF からページごとに文字を取り出し、NFKC で正規化しています。文字コードの対応表が無いフォントの文字は、Adobe-Japan1 の CID とみなして文字に戻しています。図や写真は取り込んでいません
- 計画・通知等: 国土交通白書と同じ方法でページごとに文字を取り出しています
- 交通量・指数などの値そのものは変更していません

## 使い方

東京都の区間を、昼間 12 時間交通量の多い順に並べる:

```sql
SELECT route_name, city_code, volume_12h, congestion_degree, roadside_type
FROM mlit.road.traffic_census_section
WHERE prefecture_code = '13' AND up_observation_type = '観測'
ORDER BY volume_12h DESC
LIMIT 20;
```

## 道路交通センサスの注意

- 対象は高速自動車国道・都市高速道路・一般国道・主要地方道（都道府県道・指定市市道）・一般都道府県道・指定市の一般市道の 7 区分で、一般市町村道は調査の対象外です
- 交通量は全区間が実測ではありません。観測・非観測の別が「非観測（推定値）」の区間（全国の約 3 割）は、平成27年度調査の交通量と両年度で観測した区間のデータから推定した値です。「データなし（推定不能）」の区間は交通量が NULL です
- 交通量の調査単位（交通量調査単位区間）は交通調査基本区間を集約したもので、同じ交通量が隣り合う複数の基本区間に付きます。区間数を数えて何本の道が混んでいるかを比べることはできません
- `traffic_census_hourly` は交通量調査単位区間の単位です。`traffic_census_section` とは `(traffic_pref_city_code, traffic_survey_unit_id) = (pref_city_code, survey_unit_id)` で結合できますが、1 つの観測値が複数の基本区間に付くので、基本区間をまたいで合計すると二重に数えます。合計は `traffic_census_hourly` の単位のまま行ってください
- 調査の 1 日は 7 時台に始まり翌 6 時台に終わります。時刻順の並べ替えには `hour_order` を使ってください。昼間 12 時間交通量は 7 時台〜18 時台の合計です（`is_daytime_12h`）
- 非観測でも個別調査の観測値を使った区間は、その調査の観測日を持ち、令和3年度より前のことがあります
- 混雑度は交通量を交通容量で割った値で、1.0 を超えると需要が容量を上回っています。昼夜率は 24 時間交通量 ÷ 昼間 12 時間交通量です
- 代表沿道状況（`roadside_type`）と交通量を組み合わせると、人通りのある商業地の道と通過交通の多い道を分けられます
- 区間の形は、可視化ツールが配信するタイルを区間番号でまとめたものです。タイルの境界で切れた線分を集めて 1 つの MultiLineString にしています。配信時に座標が小数 5 桁（約 1m）に丸められているため、原典の精度そのものではありません。形が得られなかった区間（99,417 区間中 350 区間、0.35%）は `geometry` が NULL です
- 配布 CSV は北海道〜茨城（都道府県コード 01〜09）でコード類の先頭の 0 が落ちているため、区間番号は 11 桁、市区町村コードと都道府県指定市コードは 5 桁に統一しています
- 年度をまたぐ突合は `section_id_h27`（平成27年度の区間番号）で行います。番号が同じでも別の区間のことがあります

## 不動産価格指数・取引件数の注意

- 住宅と取引件数の地域は、全国・地方ブロック 9 区分・都市圏 3 区分（南関東圏・名古屋圏・京阪神圏）・東京都・愛知県・大阪府の 16 区分です。上位と下位の地域が同じテーブルに並ぶので、合計や平均は地域の階層をまたがないように絞ってください
- 商業用不動産の地域番号は、住宅の地域番号と対応しません。南関東圏は倉庫・工場を公表しておらず、商業用不動産総合・建物付土地総合も無いため、6 用途だけです
- 季節調整値と原系列を `adjustment` で分けています。変化率は季節調整値が前月比（商業用は前期比）、原系列が前年同月比（前年同期比）です。サンプル数が少ない地域・用途は振れが大きくなります
- 取り込むのは国土交通省が集計する 2008 年 4 月（商業用は 2008 年第 2 四半期）以降です。住宅の都府県シートにある 2008 年 3 月以前の系列と、商業用の都府県シート（1984 年からの年次）は、各都府県の不動産鑑定士協会を出典として明示するよう注記がある系列なので取り込んでいません
- 取引件数は、建物の移転登記と土地の移転登記を突き合わせられた取引だけを数えたもので、主に中古が対象です。既存住宅販売量指数の販売量とは一致しません。取引から約 3 か月後に公表され、公表後 3 か月は改訂されます
- 取引主体別の 4 区分（個人→個人など。矢印は売り手→買い手）を足しても、取引件数にわずかに届きません。公表資料が空欄の月（地方ブロックの小さい用途など）は行がありません

## 建設工事費デフレーターの注意

- 名目の工事費をこの指数で割って 100 を掛けると、2020 年度価格の実質額になります
- 工事種類は 75 系列です。建設総合の下に、建築（住宅・非住宅を木造・鉄筋RC・鉄骨Sなどの構造別に）、建築補修、土木（公共事業の治水・道路・下水道・港湾など、その他土木の鉄道軌道・電力など）が階層で並び、上位の括りと内訳が同じテーブルにあります。`category_path` か `level` で絞ってから使ってください
- `category` は名前だけでは一意になりません（住宅と非住宅の両方に「鉄筋RC」があります）。一意なのは `category_path` です
- 道路2(再掲)・街路2(再掲)は他の系列を組み直した再掲です。ほかに、上の括りを持たない構造別・用途別の 15 系列（W在来住宅、RC学校、S工場・倉庫など）があります
- 見出しは 8 段で、括りが途中で終わる列は残りの段に同じ名前が繰り返し入っています。その他土木の内訳の「その他土木」は、段を畳むと括りそのものの列と同じになるため、`category_path` を「建設総合 > 土木総合 > その他土木 > その他土木」としています
- 月次は毎月末に 2 か月前の月が追加されます
- 年度次は古い年度ほど公表されている系列が少なく、公表されていない年度の行はありません。1951〜1959 年度は治水・道路・公園・下水道などの土木の一部だけで、建設総合は 1960 年度から、構造別・用途別の 15 系列は 1990 年度から、建築補修は 2015 年度からです
- ウエイトは 2022 年度までは各年度の建設投資の実績、2023 年度以降は 2020〜2022 年度の平均を暫定的に使っています（年度次の `is_provisional`）。営業余剰や消費税などの間接税はウエイトに含まず、用地費と補償費は対象外です

## 公共工事設計労務単価の注意

- 農林水産省と国土交通省が、毎年の公共事業労務費調査で集めた賃金の支払い実態をもとに、都道府県ごと・職種ごとに決める単価です
- 単価は所定労働時間内 8 時間当たりの円で、基本給相当額・基準内手当・臨時の給与（賞与等）・実物給与を含みます。時間外・休日・深夜の割増賃金と、法定福利費（事業主負担分）などの現場管理費・一般管理費は含みません
- 単価表は記者発表の PDF の 1 ページに 10 職種 × 47 都道府県で 5 ページあります。同じ PDF の後ろにある、必要経費を含めた金額を併記した参考公表の表は取り込んでいません
- 年度の表記で公表された 2012・2013 年度の `applied_from` は 4 月 1 日です
- 調査で十分な標本が得られなかった職種・都道府県は単価が設定されず、行がありません。屋根ふき工は 2020 年 3 月適用分から、建築ブロック工は 2014 年 2 月適用分まで単価があり、タイル工は 2017 年 3 月・2018 年 3 月適用分に単価がありません
- 2021 年 3 月・2022 年 3 月適用分は、新型コロナウイルス感染症の影響下の特別措置として前年度を下回った単価を前年度に据え置いています。公表資料で < > に囲まれた単価が `is_held_over = true` です
- 2022 年 3 月適用分までの岩手県・宮城県・福島県には、ほかと別に定めた単価があり、公表資料で ( ) に囲まれた単価が `is_disaster_area_rate = true` です。2012 年 4 月分は同年 2 月 20 日の臨時改定から適用している単価、2013 年度以降は入札不調の発生状況等に応じた単価です
- 2014 年 4 月は同年 2 月の単価を引き続き適用すると告知されただけなので、行がありません。岩手県・宮城県・福島県だけを対象にした 2012 年 2 月・6 月の臨時の改定は、それぞれの適用開始月の行としては取り込んでいません。2 月の改定の単価は 2012 年 4 月分の括弧書きとして入っています

## 行政処分の注意

- 国土交通省のネガティブ情報等検索サイトのうち、被処分者が事業者の 18 分野（建設業者・測量業者・建設コンサルタント・地質調査業者・補償コンサルタント・指名停止・宅地建物取引業者・マンション管理業者・賃貸住宅管理業者等・住宅宿泊管理業者・不動産鑑定業者・指定確認検査機関・指定構造計算適合性判定機関・登録住宅性能評価機関・鉄道事業者・船舶運航事業者・航空運送事業者・自動車整備事業者）を取り込んでいます。被処分者が個人の資格者の分野（一級建築士・建築基準適合判定資格者・構造計算適合判定資格者・不動産鑑定士・建築物調査員等）は取り込んでいません
- 自動車運送事業者（バス・トラック・タクシー）と旅行業者の処分は、検索サイトから別のページに分かれているため、このテーブルにはありません
- 検索サイトに載っているのはおおむね過去 5 年分です。古い処分は検索サイトから消えるので、テーブルからも消えます
- 1 つの違反に複数の処分（営業停止と指示など）が出ると、処分ごとに行が分かれます。同じ処分が分野をまたいで載ることもあります（建設業者と指名停止など）
- 法人番号は検索サイトに載っている行だけにあります。法人番号が無く、名前に法人の種類（株式会社・有限会社など）も無い行は、個人事業主として取り込んでいません
- 指名停止（`field = '指名停止'`）は、国土交通省の発注機関が自らの入札への参加を止める措置で、建設業法などに基づく処分ではありません
- 所在地は市区町村までの行が多く、番地までの行もあります

## 入札結果の注意

- 収録しているのは北海道開発局と東北・関東・近畿・四国・九州の地方整備局です。中部・北陸・中国の地方整備局は、入札結果データの Excel の掲載ページを確認できていないため入っていません
- 各局の掲載は今年度と前年度の分が中心です（近畿は令和 4 年度、北海道は令和 3 年度から）。このデータセットは毎月取得して原本を保存し続けるので、取得を始めた後の分は掲載ページから消えても残ります
- 原本は Excel のまま、このデータセットのアセット（`assets/<sha256>`）として保存しています。`bid.source_file` が原本の一覧で、`bid_result` はその全原本から毎回作り直します。同じ URL のファイルが差し替えられたときは一番新しい原本を使います
- 同じ入札が複数のファイルに載るとき（関東の年度まとめと月ごとのファイルなど）は、局・工事か業務か・部局・案件名・入札日・業者名が同じ行を 1 行にまとめ、後から掲載されたファイルの行を残します
- 法人番号は四国地方整備局の行だけにあります。ほかの局は業者名が「（株）」などの略記で、近畿（と東北の一部）は本店住所も持ちます
- 金額は税抜きの円です。随意契約（プロポーザル方式を含む）では見積金額が契約金額で、落札者の備考は「決定」です

## 国土交通白書の注意

- 本文は PDF から取り出した文字です。段組みや図の中の文字は、読む順が前後することがあります
- 図の軸の数字など、ごく一部の文字は正しく戻せていません。`cid_repaired_chars` は、そのページで CID から戻した文字の数です
- `page` は PDF の先頭から数えたページ、`page_label` は紙面に印刷されたページ番号です
- 図表には国土交通省以外の著作物が含まれることがあります。このデータセットは本文の文字だけを持ち、PDF の原本は保存していません

「下水道管路」を含むページを、BM25 の順に並べる:

```sql
WITH q AS (
    SELECT DISTINCT substr(w, i, 2) AS gram
    FROM (SELECT '下水道管路' AS w), range(1, length(w)) AS r(i)
),
hits AS (SELECT b.* FROM mlit.white_paper.page_bigrams AS b JOIN q USING (gram)),
len AS (SELECT sha256, page, sum(tf) AS dl FROM mlit.white_paper.page_bigrams GROUP BY ALL),
stats AS (SELECT count(*) AS n, avg(dl) AS avgdl FROM len),
df AS (SELECT gram, count(*) AS df FROM hits GROUP BY gram)
SELECT p.edition, p.page, p.page_url,
    sum(ln(1 + (s.n - df.df + 0.5) / (df.df + 0.5)) * h.tf * 2.2
        / (h.tf + 1.2 * (0.25 + 0.75 * l.dl / s.avgdl))) AS score
FROM hits AS h
JOIN df USING (gram)
JOIN len AS l USING (sha256, page)
JOIN mlit.white_paper.pages AS p USING (sha256, page)
CROSS JOIN stats AS s
GROUP BY ALL
HAVING count(*) = (SELECT count(*) FROM q)
ORDER BY score DESC
LIMIT 5;
```

## 計画・通知等の注意

- 行政事業レビューのシート（2024 年度から）の「関係する計画・通知等」の URL のうち、www.mlit.go.jp の PDF だけを取り込んでいます。ほかのサイトの文書と HTML のページは入っていません
- シートの URL には、すでに消えたページ（404）が含まれます。取得できなかった URL は `plans.documents` に入っていません
- `fetched_at` は PDF を取得した日時です。国土交通省のサイトで PDF が差し替えられていると、中身が違うことがあります
- 全文検索の索引は持っていません。`plans.pages` の `text` を検索してください

## ビルド

```bash
git submodule update --init
uv sync
bash scripts/build.sh
```

`main.py` が次の原典を取得して Parquet にし、dbt build で各テーブルを作り直します。

- 道路交通センサス: 箇所別基本表と時間帯別交通量表の CSV（47 都道府県分）と、区間の形の GeoJSON タイル。タイルは区間ごとにまとめます
- 不動産価格指数・取引件数: 掲載ページから「最新データ」の Excel の URL を資料名で引いて取得し、横持ちの表を縦持ちにします
- 建設工事費デフレーター: 統計表のページから月次・年度次の Excel をファイル名の接頭辞で引いて取得します
- 公共工事設計労務単価: 案内ページから改定ごとの記者発表をたどって PDF を取得します。公表済みの PDF は差し替わらないので、取得済みのものは取り直しません
- 行政処分: 分野ごとに検索結果の一覧の全ページと、1 件ごとの概要のページを、1 秒に 1 回の頻度で取得します（全分野で約 4,000 ページ、約 1 時間）。概要のページは取得済みなら取り直しません
- 入札結果: 局の掲載ページ（年度別のページを含む）から Excel のリンクを集めて取得し、原本を `data/assets/<sha256>.<拡張子>` に置きます。`scripts/build.sh` が `FDL_ASSETS` にこのフォルダを渡し、`fdl commit` がリポジトリに無い原本だけを上げます。原本の一覧は前のバージョンの `bid.source_file` を引き継ぎ、手元に無い原本はリポジトリのアセットから取得します
- 国土交通白書: 年版ごとの一括 PDF を取得し、PyMuPDF でページごとに文字を取り出します。CID から文字に戻す対応表は、Adobe の [mapping-resources-pdf](https://github.com/adobe-type-tools/mapping-resources-pdf) の Adobe-Japan1-UCS2 をコミットを固定して取得します
- 計画・通知等: 行政事業レビューのシートをテーブルにした Queria の公開データセット queria/rssystem の `review.related_plans` から www.mlit.go.jp の PDF の URL を集め、1 秒に 1 回の頻度で取得します。手元で流すときは、取得済みの URL を `data/plans/index.json` で覚えて取り直しません。取得と Parquet 化は dataset-shared の `review_plans.py` で行います

GitHub Actions の定期実行（毎月 11 日）では、行政処分・入札結果だけを取り直します（`python main.py monthly` と同じ）。ほかのテーブルは前のバージョンのまま残ります。

タイルの配信元はディレクトリ一覧を返さないので、どのタイルがあるかを 2 段階で調べてリポジトリに置いています。

1. 候補の索引 `tools/tile_index_z12.csv`（`uv run python tools/build_tile_index.py`）。国土数値情報の都道府県境界に掛かる z12 タイルを 8 近傍に広げたもので、10,483 タイルあります
2. 実在するタイルの一覧 `tools/tile_list_z12.csv`（`uv run python tools/build_tile_list.py`）。候補を道路種別の 6 層すべてで取得し、配信されていたものだけを残します。6 層で 18,004 枚あります

取得は 2 の一覧だけを、4 本並列・全体で毎秒 5 リクエストまでの頻度で実行します（約 1 時間）。候補を全部取得すると約 6.3 万リクエストになり、7 割あまりは配信の無いタイルで 404 になります。GitHub Actions のランナーからは 1 リクエスト 0.6 秒ほどかかるので、全部取得すると Sync の時間制限（300 分）に間に合いません。令和3年度のタイルは更新されないので、一覧は調査年度ごとに 1 回作れば足ります。
